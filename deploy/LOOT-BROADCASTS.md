# 稀有裝備掉落廣播與裝備標記

## 全服跑馬燈

- 怪物掉落的傳說 (`legend`) 或遺物 (`relic`) 武器、防具、飾品會建立掉寶紀錄。箭矢、消耗品、普通裝備不廣播。
- 怪物掉落後隨雲端存檔同步，其他玩家通常在約 3～7 秒內收到通知。CLI 玩家同步週期依 CLI 設定。
- 內容包含角色名、地圖、怪物、裝備類別與名稱。手機顯示於導覽分頁下方；電腦顯示於冒險地圖上方。廣播不覆蓋戰場，可以略過當前訊息。
- 多筆通知依序播放，降低動態效果的瀏覽器設定會顯示可左右捲動的靜態文字。
- 購買、製作、倉庫取出、GM 發物及已持有的裝備不廣播。登入時從最新游標開始，不重播舊通知。
- 掉寶紀錄保留在角色存檔中，伺服器在同一存檔交易中登記與去重；重送、斷線重連及伺服器重啟不重複廣播。最多保留每角色最近 64 筆待同步來源紀錄；極端高倍率導致單次同步間超過 64 筆稀有掉落時，較舊訊息可能省略。
- 接收端查詢最近 10 分鐘的新廣播，資料庫保留約 1,000 筆公告。一般玩家只能讀取廣播，沒有任意提交公告文字的 API。

伺服器核對物品目錄的稀有標記、裝備類型、來源怪物與地圖，公告名稱取自伺服器資料。實際戰鬥仍採現有客戶端引擎，這項核對不等於伺服器完整驗算掉寶。

## 現有裝備分類

遊戲沒有一套白、綠、藍、紫、金的統一稀有度數值。明確分類是一般裝備、傳說、遺物；傳說與遺物屬於不同設計類型，不能直接視為戰力排序。

| 分類或標記 | 意義 |
| --- | --- |
| 一般裝備 | 無 `legend` / `relic` 標記；仍可能有祝福、遠古、屬性等詞綴 |
| 傳說 | `legend`，名稱金橘色；掉落日誌標示 `✦` |
| 遺物 | `relic`，名稱海藍色；有特殊能力，不能強化、賦予屬性或取得祝福／遠古詞綴；掉落日誌標示 `✦` |
| 祝福／詛咒、遠古／永恆／不朽／太初 | 能力詞綴或變體；不是依序升級的稀有度階梯 |
| 席琳套裝綠字 | 套裝效果標記；不是通用綠色品質 |
| `★` / `★★` / `★★★` | 五階屬性武器的附加魔法星級，觸發機率＝該技能基礎機率 × 星數，最高三星 |
| `+N` | 裝備強化值，與星級分開 |

## 星級的取得與例子

符合条件的非遺物武器達五階屬性後，再使用同屬性卷軸可按既有 1% 成功率附加／重抽魔法。同技能成功再抽到會升一星，最高三星；改抽到不同技能會回到一星。部分原生帶攻擊觸發技能的武器無法附加。

例如基礎觸發率 5% 的魔法：一星為 5%、二星 10%、三星 15%。星級提高觸發機率，並非把武器傷害直接乘以星數。

程式依據：`js/08-items-equip.js` 的 `getItemColor`、`getItemFullName`、`getAttrMagicProc`，以及 `js/11-world-map.js` 的 `doBianAttr`。
