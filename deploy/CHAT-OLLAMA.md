# 世界聊天、線上玩家與本機 Ollama

## 玩家介面

- 冒險地圖框內的工具列顯示帳號、同步狀態燈、線上人數、聊天及 `⋯` 設定，隨頁面正常排列，主要觸控按鈕至少 44px。
- 點「線上 N」開啟玩家名單，列出角色、地圖及 AI／GM 標示；同帳號只計一次。總數另列一般玩家與 AI 角色數，每 10 秒更新，控制權逾期（45 秒）後不再計入。
- 世界頻道集中於同一視窗的「玩家聊天／NPC 對話／線上玩家」分頁。原 NPC 對話節點直接搬移，發問及服務連結仍沿用；戰鬥傷害與掉寶日誌仍在冒險畫面下方。
- 玩家聊天每 4 秒更新；視窗關閉時不抓聊天紀錄。向上閱讀不因新訊息直接捲到底。

## GM 切換本機模型

1. 前往 `/gm` →「AI 聊天」，將執行方式選為「本機 Ollama」。
2. Ollama 網址預設 `http://127.0.0.1:11434`，可改本機連接埠。`localhost` 指**執行聊天橋接程式的電腦**。
3. 輸入已安裝模型名稱，或從回報清單選擇。本機現有 `qwen3:8b`；此功能不自動下載模型。
4. 保留或調整發言角色、話題、間隔、回覆玩家及每日生成上限後儲存。`0` 代表每日不限。
5. 約 10 秒內回報連線及模型狀態。可用「立即要求一次發言」測試；仍遵守最短 30 秒排程間隔。

Railway 僅排程與保存設定；本機橋接程式向 Railway 領取工作，再呼叫自己的 Ollama。毋須將 11434 連接埠公開到網際網路，也不須提供 OpenAI API 金鑰。Ollama、聊天橋接程式與電腦須保持運作，休眠或關機時停止產生新回覆。

## 本機啟停

於遊戲專案目錄執行：

```powershell
# Ollama 桌面程式已運作時，不必再啟動 serve。
ollama serve
# 在另一個終端執行：
node cli/ai-chat.mjs start
node cli/ai-chat.mjs status
# 暫停自動聊天（不影響四職練功）：
node cli/ai-chat.mjs stop
```

橋接憑證沿用本機 `data/cli/ai-chat/bridge.json`，只授權聊天工作，不具 GM 或玩家操作權限；檔案已排除上傳。未另設開機自動啟動。

## 行為與驗證

- 本機網址只接受 loopback、拒絕重新導向，模型清單排除雲端模型。Ollama 請求不含遊戲 Cookie 或橋接 token。
- 僅要求結構化文字回覆，不提供工具。生成逾時、失敗或缺少模型時不發話；GM 變更設定、停用或重新授權會取消舊工作。
- AI 發言使用原有四職帳號與標示；一般玩家訊息可作為回覆上下文。NPC 對話仍屬原遊戲機制。
- 新增自動測試涵蓋本機模型、橋接流程、取消舊回覆、GM 表單、線上計數與聊天分頁。完整測試 118 項通過。
- 本機 `qwen3:8b` 實際生成繁體中文成功；隔離瀏覽器驗證 390px／360px 手機與桌面版、玩家發話、NPC 回覆、線上名單、設定選單及 GM 儲存，無 JS 錯誤。

官方介面參考：[Ollama Chat](https://docs.ollama.com/api/chat)、[模型清單](https://docs.ollama.com/api/tags)。
